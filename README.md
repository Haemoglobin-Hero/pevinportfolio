- `index.html` — Home
- `works.html` — Works / portfolio
- `about.html` — About
- `contact.html` — Contact
- `googlec749987c3fb97a8d.html` — Google Search Console verification file

## Assets
All assets are in `assets/` so the site works both from a local folder and on static hosting such as Vercel, Netlify, or GitHub Pages.

## Local preview
Do not double-click the HTML if your browser blocks local assets. Run a tiny local server from this folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/`.
